# ATTRACT MODE — master build prompt (v2, "keynote-grade")

## Role
You are a principal real-time graphics engineer and title-sequence designer. You ship GPU keynote reels, AAA attract screens and broadcast graphics. You write raw WebGL2 and GLSL ES 3.0 by hand. You hold yourself to 60 fps, zero stutter, zero console errors and pixel-level typographic polish.

## Mission
Build **attract.html**: one self-contained file that plays a fullscreen, endlessly looping, cinematic "attract mode" for the Grid Doomsday Finder stall (team Cascade Sentinel, Q-Hack India 2026).
- It runs unattended on a presentation laptop for 8+ hours.
- It must stop people walking past.
- It must teach the project's whole story in 90 seconds, using only real data.

## Hard constraints
1. **Offline, single file.** Double-click must work from `file://`. No CDN, no fetch, no ES-module imports, no external fonts. Fonts are embedded as base64 woff2. Data is embedded as a JSON literal generated by a build script from the project's own files.
2. **No library.** Use raw WebGL2. Write the small matrix/vector maths yourself. This gives total control of the pipeline and zero dependency risk.
3. **Real data only.**
   - IEEE-118 layout and branches come from `grid_ieee118.json`.
   - The cascade comes from `top_cascades_ieee118_k3.json[0].dc` (outage {6, 67, 140}): per-round `out_of_service`, `tripped`, `overloaded`, `loading`, `energized_buses` and `load_served`.
   - Every number on screen comes from either that data or one constants block: 1,055,240 candidates; 79.2 % harmless; 122 severe; Grover ≈ 807 queries; ≈ 33,000× slower (realistic estimate); 538,008 logical qubits; 8.70 × 10⁹ Toffoli per iteration; exhaustive ≈ 2 h on one core vs ≈ 7.4 years for quantum.
   - The numbers derived from the cascade must equal the project's: 97 trips, 7 rounds, 31 buses dark, 22.8 % unserved, branch 110 at 612 % of rating.
4. **Honesty is part of the design.**
   - Each data moment carries an evidence chip: SIM (simulator), EMU (exact emulation of a quantum algorithm) or EST (estimate).
   - A persistent footer line states: benchmark network, synthetic ratings, no quantum hardware run, no quantum advantage claimed.
   - Never use the words "live", "real-time threat" or "prediction".
5. **No trademarks.** No logos or names of real companies.

## Visual language
- **Night-sky grid.** The network is a constellation of lights over a dark world. The only light in the frame encodes data: lit demand, power flow, failures and quantum amplitude.
- **Palette (HDR, linear).**
  - Void: #04060B → #0A1220.
  - Lit demand / amber: #FFB347 core, #FF7A1A halo.
  - Healthy flow / ice: #7FD4FF.
  - Failure / signal red: #FF3B2F, with a white-hot #FFF4E0 flash.
  - Quantum / violet: #9B7CFF.
  - HUD text: #E8ECF1 and #8A93A0.
- **Look stack.** HDR render → threshold + 6-level dual-filter bloom → screen-space shockwave refraction → radial chromatic aberration → ACES filmic tone map → vignette → animated film grain → faint scanlines. Volumetric feel from distance fog plus a procedural haze/star backdrop and a perspective ground grid that fades into darkness.
- **Typography.** Archivo (700 / 500) uppercase with wide tracking for titles; JetBrains Mono for telemetry. The HUD reads like flight instruments:
  - corner brackets;
  - a sequence index "SEQ 03/07";
  - a loop progress bar;
  - a live telemetry column (lines in service, buses energised, islands, demand served, trips, round);
  - odometer-rolling digits;
  - draw-on brackets.

## Engineering
- **One master clock and pure functions.**
  - `state(t)` computes camera, bus brightness, branch heat/visibility/flash/burn, galaxy reveal/sweep/amplitude and HUD content from t alone. Seeking is exact.
  - Per-frame dynamic state is uploaded as two tiny float textures (bus 118×2, branch 186×2) read with texelFetch. Static geometry is uploaded once.
- **Geometry.**
  - Branch ribbons: indexed triangle strips (28 segments per arc), expanded to constant screen width in the vertex shader.
  - Flow particles: N per branch, positioned on the arc in the vertex shader.
  - City lights and nodes: point sprites.
  - Galaxy: `drawArrays(POINTS, 0, n)` with an empty VAO.
  - Everything additive-blended into an RGBA16F target (with RGBA8 fallback).
- **Camera.** Spherical rig (target, radius, elevation, azimuth) with eased keyframes and shake impulses.
- **Adaptive quality.**
  - Measure the 2-second mean frame time.
  - Step down in this order: render scale (1.0 → 0.85 → 0.7 → 0.55) → particle density → galaxy draw count (HUD numbers stay exact) → bloom levels.
  - Step up after 6 s of headroom.
- **Kiosk.**
  - Keys: F fullscreen, H toggle HUD, 1–7 jump to scene, Space/P pause, ←/→ seek ±5 s, D debug overlay (fps, ms, quality, draw calls), M ambient Web Audio drone with strike thumps (off by default; starts only on a gesture).
  - Behaviour: cursor auto-hides; Wake Lock with graceful refusal; render stops when the tab is hidden; WebGL context loss and restore rebuild everything; resize-safe at any aspect ratio; `prefers-reduced-motion` gives a calm cut (no shake, no flashes, softer bloom).
  - URL parameters: `?t=SECONDS&still=1&q=high`, for capturing stills.
- **Soak safety.** No allocations in the frame loop (preallocated typed arrays), no growing structures, no timers except requestAnimationFrame.
